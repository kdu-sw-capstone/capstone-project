# develop 최신 반영 내역

GitHub에는 변경하지 않았으며 다운로드 원본도 수정하지 않았다. 이 폴더는 기존 develop 구조를 유지한 교체·검토용 사본이다.

- frontend/backend/extension 폴더 유지, README의 개발 계획 링크 갱신.
- 최신 설계·도면·밝은 미리보기와 AI 개발 규칙·47개 작업카드 반영.
- 협업 문서·PR·Issue 양식과 현재 문서 진입점 통일.
- 기존 문서·발표 도면·화면 엑셀은 archive/develop_정리전_자료.zip에 원형 보관.
- 개인별 개발 담당은 추정하지 않음. 실제 소스 구현·테스트 실행 없음.
- 기존 .env.example과 .gitignore는 그대로 보존.
