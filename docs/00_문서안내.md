# FOCURVE 설계 문서

기준일: 2026-09-25

FOCURVE는 학습·업무 목적에 맞게 사이트 이용 환경을 설정하고, 집중 세션 중 자동으로 수집한 접근·반복 접근 기록을 확인하여 다음 집중 환경을 조정하는 서비스다.

2026학년도 3학년 2학기 개발 범위는 **Web·Chrome Extension·Server의 기본 기능과 추가 기능 전체**다. 기능 구현, 설계 검수, 통합·회귀 테스트를 학기 내 완료한다. PC 확장은 이 완료 기준을 모두 충족한 뒤 인력과 일정에 여유가 있을 때 착수한다.

기본 MVP와 추가 기능은 구현 순서를 구분하는 용어다. 추가 기능을 임의 선택 또는 차기 학기 이월 대상으로 해석하지 않는다. Chrome Extension은 이번 학기 웹 서비스의 실행 구성요소이며, 별도 설치형 PC 프로그램인 FOCURVE Desktop과 구분한다.

화면 설계, 기능 구현, 실행 테스트는 별도로 판정한다. 설계 문서와 프로토타입의 존재만으로 기능 구현 또는 테스트 완료를 판정하지 않는다.
