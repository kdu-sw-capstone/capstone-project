PR #17 Core와 #21 Content의 코드가 merge 기준에 successor 형태로 포함됐어도 원래 PR 승인/병합을 뜻하지 않는다. D06 enum·scope·operation·release 의미를 이 RC1로 덮어쓰지 않는다. PR #22 기존 설계는 근거이며 본 PR은 별도 변경만 담는다. head별 겹침은 검증 결과의 PR 관계 표를 참조한다.

**BREAKING_IF_ROUTED_TO_LEGACY**: 새 stream/enum/Scope/정책을 구형 API·D06 actor에 전달하는 동작, Event1.2에 신규 필드를 추가하는 동작, Journal1.1 재직렬화, 기존 auth를 capability 문자열로 대체하는 동작. RC1은 별도 namespace + 검증된 capability 미지원 시 사전 거절로 이를 방지하도록 설계했다. 구형 Server 404는 미지원, 401은 인증 실패, timeout/5xx는 UNKNOWN이며 성공으로 치환하지 않는다.


추가 확인된 구현 차이: 기존 `extension/content/keyword.mjs`는 TITLE/BODY scopes와 substring/includes를 지원하므로 확정 URL전용·경계 규칙을 그대로 재사용할 수 없다. 신규 URL_BOUNDARY_1 adapter를 분리하고 기존 미지원 active profile은 거절한다. `features.mjs`의 recommendations는 home와 watch를 함께 가리므로 YT-01 홈/04 watch추천을 별개 options로 매핑해야 한다. 기존 Content flag 지원이 전체16/실제Core wire 지원을 뜻하지 않는다. 기존 MemberApi의 pause/resume은422 FEATURE_NOT_IMPLEMENTED이며 note는 MemberSessionNotes GET/PUT이다.


기존 task card 실제 제목 대조 후 OPTION-04=집중예약, OPTION-06=사이트이용시간, OPTION-08=시간대별패턴·확장분석으로 연결했다. traceability.task_card_refs는 실제존재파일을 자동검증한다. 초기 초안의 OPTION-08 예약 표기는 정정했다. 원본 상세 API defaults와 최신 사용자 정책 사이의 의미 차이는 위 adapter gate에서 해소하며 기존문서를 무단 수정하지 않는다.
