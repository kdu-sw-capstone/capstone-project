## UI 상태 계약

설정 저장 완료 ≠ 실제 적용 완료. 대시보드·집중 세션은 현재 frozen 설정과 다음 세션 설정을 분리한다. 지원하지 않는 기능은 비활성 이유·정확한 서비스 범위를 표시한다. 모델/목록 로딩 실패를 보호중으로 표시하지 않는다. PAUSING/ENDING/UNKNOWN은 실제 해제 미확인 상태로 표시하고 시작확인중 사용자 CANCEL 버튼을 만들지 않는다.

지표 0/null/미수집/전송대기/일부수집, 초과 예정/실제 차단확인/실패를 구분한다. 한도 해제는 실제 규칙 확인 전 성공으로 표시하지 않는다. 확정 요구16개 모두 설정·현재적용·오류/미지원·도움말·다음세션 상태에 접근 가능해야 한다.
