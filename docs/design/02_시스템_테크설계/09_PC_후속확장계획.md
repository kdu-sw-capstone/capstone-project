# 개발 단계와 PC 후속 확장 계획

## 확정된 진행 방향

**필수 MVP → 추가 MVP 완료·검증 → PC 앱 확장** 순서로 진행한다. PC 확장은 예정된 후속 개발이다. 현재 상세 설계는 Web·Server·Chrome Extension을 기준으로 하며, PC를 영구 제외한다는 뜻이 아니다. 모바일 확장은 아직 결정하지 않았다.

| 단계 | 개발 대상 | 설계·완료 기준 |
|---|---|---|
| 1. 필수 MVP | Web·Server·Chrome Extension, 필수 33개 기능 | 현행 명세·작업카드에 따라 구현하고 실제 연동 검증 |
| 2. 추가 MVP | 같은 구성의 추가 14개 기능 | 추가 기능 검증 및 필수 기능 회귀·전체 연동 검증 |
| 3. PC 앱 확장 | PC에 설치하는 앱과 PC 프로그램 관리 기능 | 앞 단계 완료·검증 후 PC 상세 설계와 구현 진행 |

현재 47개 기능 ID와 수용 기준은 1·2단계 기준이다. PC 확장 계획을 추가했다는 이유로 기존 기능을 삭제하거나 완료로 표시하지 않는다. PC는 기존 47개 기능에 이미 상세 설계된 것으로 집계하지 않는다.

## 전체 구성과 담당 경계

- Web 대시보드: 설정·요청·기록·통계의 사용자 화면.
- Server·DB: 인증·권한·회원 데이터·집계. 현재 계약을 유지한다.
- Chrome Extension: 브라우저 사이트·페이지 내부 기능 제어, 적용·해제 결과 및 이벤트 수집, 비회원 로컬 실행.
- 후속 PC 앱: PC 프로그램 관리·제어를 담당할 실행 구성 요소. Web·Server의 재사용과 연동 방식은 PC 상세 설계에서 검토한다.

현재 3인 담당 배정은 유지한다. PC 담당자·기술 스택·지원 OS·세부 일정은 아직 확정하지 않았으며 현재 담당표에서 임의 배정하지 않는다. Chrome 확장프로그램의 브라우저 제어와 PC 앱의 운영체제 수준 제어를 같은 구현으로 간주하지 않는다.

## PC 단계에서 구체화할 설계

PC 프로그램을 관리한다는 방향은 확정이다. 다음 사항은 PC 구현에 앞서 상세 설계한다.

1. 지원 OS, 앱 설치·업데이트 방식, 실행 권한과 기술 스택.
2. 관리 대상 프로그램 식별·등록 방식, 실행 감지와 제어 방식, 예외·해제·오류 복구.
3. Web·Server와 계정·설정·집중 세션·기록을 연결하는 방식과 오프라인 동작.
4. PC와 Chrome을 함께 사용할 때의 적용 상태, 기기 구분, 충돌·중복 처리.
5. 필요한 API·데이터·화면 변경, PC 작업카드와 수용 기준, 기존 Chrome 기능 회귀 검증.

현재 API·DB·이벤트 형식을 PC에 그대로 재사용할 수 있다고 단정하지 않는다. 변경이 필요하면 PC 상세 설계에서 영향 범위와 호환 방식을 정한다. 지금 미래 PC 기능을 이유로 현행 Chrome 구현 계약을 임의 변경하지 않는다.

## 일정과 AI 작업 기준

2027년 2월 개발 목표와 이후 종합 테스트·안정화 일정은 현재 Web·Server·Chrome Extension의 필수·추가 MVP 기준으로 관리한다. 개발 중에도 기능별·통합 검증을 병행한다. PC 확장의 구체 착수일·완료일은 별도 수립한다.

AI에게 현재 기능을 구현시킬 때는 현행 명세와 작업카드를 제공한다. 동시에 PC 후속 확장 계획을 보존하도록 한다. PC 상세 명세가 완성됐다고 주장하거나, 모바일 개발이 확정됐다고 해석하거나, PC를 영구 제외한다는 문구를 다시 작성하지 않는다.
