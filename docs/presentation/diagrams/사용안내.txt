구성
- draw.io 편집 원본 3개: 이번에 첨부한 IA, User Flow, Task Flow
- 전체 설계도: PNG 3개 + SVG 3개
- User_Flow_영역별: 집중 전·중·후, 계정 연결·데이터 이전 / PNG·SVG 각 4개
- Task_Flow_영역별: TF-01~TF-13 / PNG·SVG 각 13개

사용 방법
1. PPT에는 영역별 PNG를 넣고 가로·세로 비율을 유지해 크기를 조절하세요.
2. 전체 설계도는 개요용으로 사용하고, 상세 설명에서는 영역별 그림을 확대하세요.
3. SVG는 확대용 벡터 파일입니다. 사용하는 프로그램에 따라 내장 글꼴 지원이 달라질 수 있으므로, 글꼴이나 배치가 달라지면 함께 제공한 PNG를 사용하세요.
4. 내용과 연결선 수정은 draw.io 원본을 열어 진행하세요.

이번 첨부 파일을 그대로 기준으로 내보냈으며, 실행 흐름이나 문구를 추가 수정하지 않았습니다.
원본 보기(SVG) 탭 대신 전체 편집 가능 탭과 개별 영역 탭을 내보냈습니다.
PNG는 흰 배경이며, 원본 비율을 유지했습니다. 한국어 렌더링에는 Noto Sans CJK KR을 사용했습니다.
