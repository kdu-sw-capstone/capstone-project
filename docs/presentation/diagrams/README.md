# FOCURVE 설계도

draw.io는 편집용 원본, PNG·SVG는 열람·발표용 이미지입니다. Task Flow와 User Flow는 영역별 폴더에서 확대하여 확인할 수 있습니다. 현재 Task Flow 이미지 묶음은 TF-01~TF-13이며, TF-14 및 추가 기능 흐름은 [Task Flow 문서](../../design/01_UX_기능설계/FOCURVE_Task_Flow_v1.0.md)와 [추가 기능 설계](../../design/01_UX_기능설계/FOCURVE_추가_기능_설계.md)를 따릅니다. ERD 편집 원본은 [시스템 설계](../../design/02_시스템_테크설계/FOCURVE_ERD_IE_v1.0.drawio)에 있습니다.
