# 담당·협업 기준

구성원은 윤종민·김다훈·채지민이다. 개인별 담당은 팀의 기존 합의를 따르며 기능별 작업카드에 담당자와 작업 영역을 기록한다. 김다훈은 초기 저장소 관리를 맡는다.

| 영역 | 책임 |
|---|---|
| Web | 입력·설정·요청·상태 표시·기록·통계 화면 |
| Server | 인증·소유권·계정 저장·집계·API |
| Extension | 실제 정책 적용·해제·수집·로컬 보관·재전송 |
| 통합 | 영역 간 계약 확인·PR 검토·실제 연동 검증 |

## 작업 조율과 인계

- 시작 전에 기능·영역·담당을 작업카드에 기록하고 중복 작업을 확인한다.
- API·이벤트·상태·공용 파일 변경은 관련 담당자와 조율한다.
- 중단할 때 현재 변경·검증 결과·미해결 문제·다음 행동을 남긴다.
- 재개할 때 최신 작업카드와 실제 코드를 확인한다.
- PR마다 검토자와 연동 확인 담당을 정한다. 통합은 별도의 고정 인원을 새로 지정한다는 의미가 아니다.

각자의 가능한 시간에 작업하고 준비된 PR부터 검토한다. 매일 작업하거나 회의하는 것을 전제로 하지 않는다. 기능을 모두 만든 뒤 처음 연결하지 않고 작은 기능부터 실제 연동을 확인한다.

진행 상태와 완료 조건은 [개발 운영](implementation/개발운영.md), 전체 진행 요약은 [통합 현황](implementation/통합현황.md)을 따른다.
