제품 API・회원 인증・Extension 제어・필수 MVP 기능 테스트는 미실행이다. 기존 47개 기능 상태와 담당은 변경하지 않았다. 개발 기반의 작업 브랜치 Push는 완료했고 PR·공유 브랜치 병합은 아직 진행하지 않았다. Windows 검증 문서 갱신도 같은 작업 브랜치에서 관리한다.

### 2026-10-08 EXT-02 백업 재개 보완

사용자 제공 v0.1.5 비회원 구현을 기존 EXT-02 브랜치에 추가 복원하고 APPLY 기한 정각·누락/비정상 기한 복구 결함을 수정했다. 자동 테스트 37/37, 문법 검사·검증 fixture 빌드 통과. 제품 Chrome·IndexedDB·회원/Server 실제 연동은 미검증이며 EXT-02 전체 완료가 아니다. 이전 사용자 Chrome 보고는 이전 버전 결과로 분리한다. LOG-01 v0.1.6 및 다른 기능 구현은 추가하지 않았다. 상세는 [EXT-02 작업카드](tasks/EXT-02.md)의 백업 재개 기록을 따른다.


### 사용자 Chrome 기본 시나리오 결과 추가

백업 재개 수정본 안내 후 사용자가 로드·차단·실행 중 설정 변경 시 스냅샷 유지·해제·다음 세션 변경 반영·Chrome 재시작의 1~6번 모두 성공을 보고했다. 사용자 실행 결과로 기록하며 자동 37/37 및 이전 버전 보고와 구분한다. OS/Chrome 버전·실제 로드 코드 SHA는 미확인이고 EXT-02 전체·회원 연동 완료로 표시하지 않는다. 자세한 결과와 남은 경계는 EXT-02 작업카드를 따른다.

### EXT-02 비회원 도메인 경계 보완

비회원 탐색의 마지막 DNS 루트 점 및 URL host/DNR regex 일치를 수정했다. 현재 자동 검증 42/42·문법 검사·검증 fixture 빌드 통과. 기존 스냅샷·다음 세션 변경·규칙 해제 회귀 포함. Linux Chromium 압축해제 확장 로드는 관리자 정책 거절로 실제 브라우저 검증 미실행. 신규 Windows Chrome D1~D6 사용자 재검증 대기. 기존 기본 흐름 사용자 6개 성공 보고는 이전 코드 결과로 유지하며 EXT-02 전체 완료는 아니다. 자세한 배정 근거·결과는 EXT-02 카드의 최신 도메인 경계 기록을 따른다.


### EXT-02 도메인 경계 사용자 재검증 결과

9a6cc7d 최신 ZIP 안내 후 사용자가 D1~D6 모두 성공을 보고했다. 마지막 점 주소·열린 탭 차단·정확/하위 도메인 범위·유사 host 제외·스냅샷 고정/다음 세션 변경·RECORD/ALLOW 방문·종료 해제의 사용자 결과를 확보했다. 자동 42/42와 별도 기록하며 OS/Chrome 버전·실제 로드 SHA는 미확인이다. 이번 도메인 보완 단위는 검토 가능, EXT-02 전체·회원 연동 완료는 아니다. 상세는 EXT-02 작업카드 최신 사용자 재검증 기록을 따른다.
