# AI 요청문

## 처음 저장소를 전달할 때

AGENTS.md와 docs/implementation/개발운영.md, 통합현황.md를 읽고 현재 코드 상태를 확인해. 현재 구현 범위는 필수·추가 MVP의 Web·Server·Chrome Extension이다. 이를 완료·검증한 뒤 PC 앱으로 확장하는 계획을 보존해. docs/design/02_시스템_테크설계/09_PC_후속확장계획.md를 함께 읽고, 현재 Chrome 상세 명세와 후속 PC 계획을 구분해. PC를 영구 제외하거나 상세 설계가 완료됐다고 해석하지 마. 모바일은 미정이다. 설계를 다시 작성하지 말고 현행 설계에 따라 개발해. 기존 담당 배정은 유지해. 실제 코드·실행 환경에서 확인한 것과 확인하지 못한 것을 구분하고, 첫 작업의 관련 설계와 선행 조건을 정리한 뒤 구현해.

## 담당 기능 개발

담당 기능 [기능 ID], 작업 영역 [기존 담당 영역]을 구현해. 해당 작업카드와 설계연결.json에서 관련 화면·동작·API·데이터·수용 기준 원문을 읽어. 현재 브랜치와 미커밋 변경을 먼저 확인하고 다른 작업자의 수정을 보존해. 설계 임의 변경 없이 구현·검증하고 작업카드에 코드 위치, 테스트 명령과 실제 결과, 미검증, 다음 행동을 남겨. 파일이나 도구에 접근할 수 없으면 접근했다고 가정하지 마.

## 시간이 없어 중단할 때

현재 작업을 재개할 수 있도록 작업카드에 완료한 부분, 미완료, 변경 파일, 실행 방법, 테스트 결과, 문제와 다음 행동을 기록해. 검증하지 않은 부분은 완료로 표시하지 마. 공유 브랜치에 임의 병합하지 마.

## 다음에 재개할 때

## 통합 검토

[PR 또는 변경 범위]를 현재 설계와 비교해. 기능 ID별 코드 위치와 수용 기준을 연결하고 Web·Server·Extension 계약 차이, 정상·오류·중복·복구 경로를 확인해. 필요한 수정과 검증을 수행하고 실행 결과를 기록해. 미실행·모의 검증을 실제 연동 성공으로 표시하지 마. 통합현황과 작업카드를 결과에 맞게 갱신해.

## 일반 채팅에 전달하는 경우

위 요청문과 함께 AGENTS.md, 해당 작업카드, 연결된 명세 원문과 최신 코드를 제공한다. 파일을 찾을 수 있는지 AI가 확인하게 한다. 코드 실행 도구가 없으면 실제 개발 환경에서 테스트를 실행해 결과를 전달한다. 텍스트 코드 생성만으로 실행 검증이 완료되지는 않는다.
