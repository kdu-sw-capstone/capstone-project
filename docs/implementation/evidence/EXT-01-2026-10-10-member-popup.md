# EXT-01 화면 · 회원/비회원 팝업 안내 · 2026-10-10

이번 목표: 회원은 Web에서 시작·설정을 관리하고 Extension에서 실제 실행을 확인하도록 안내한다. 보존된 비회원 자료와 회원 정책을 혼동하지 않도록 구분한다.

기능 카드 EXT-01 정책 동기화의 전체 구현 완료가 아닌 EXT-01 화면 개선이다. 시작 4e4c44e81947021fe10063ab511904ecc4d84558, 담당 Core 종민, feature/extension-core-ext-02, Extension 0.1.16, PR #17.

## 기준·구현

`docs/design/01_UX_기능설계/02_IA_화면명세.md` EXT-01 및 회원/비회원 경로: 회원 관리→Web, 실제 실행 상태는 Extension, 보존 비회원 자료는 별도 로컬 경로, 로그인만으로 업로드하지 않음.

- 회원 연결/인증 복구 상태에서 회원 안내와 기존 실제 실행 확인 버튼을 제공한다. Web 링크는 HTTPS 또는 로컬 개발 HTTP origin만 허용하며 자격증명·경로·query·fragment가 있으면 제거한다. 링크에 토큰/계정 ID는 넣지 않는다.
- 비회원 시작 양식 및 비회원 정책 요약은 회원 모드에서 숨긴다. 실제 남은 비회원 실행이 있으면 해당 해제/확인 UI는 계속 제공한다. 새 회원 시작을 확장 로컬에서 실행하지 않는다.
- 보존 비회원 기록 보기와 사이트 관리는 별도 소유 구분 안내를 유지한다. 회원 상태에서 이동/복귀해도 회원 표시가 비회원 표시로 바뀌지 않게 한다.
- 인증 복구는 새 시작 허용을 뜻하지 않는다. 기존 회원 종료/해제 확인을 제공한다. 연결 종료/응답 미확인 시 이전 Web 링크를 제거하고 기본 양식을 복구하되 미확인 상태에서 시작을 허용하지 않는다.
- Server API·정책·원문·계정 저장소 변경 없음. 기존 실행 판정은 실제 coordinator 결과를 따른다.

## 진행률 및 남은 범위

개인 Core 진행률은 현재 합의된 개인 구현/안정화 범위에서 약 80~85%로 추정한다. 정식 AC 통과 비율이나 전체 프로젝트 진행률이 아니다. 남은 큰 개인 단위는 저장 장애 시 수집 중단·해제 경계와 최신 실제 검증이다. 팀원 Shorts·lifecycle·watermark 연결과 통합 검증은 별도 남아 있다. 새 결함 발견 시 범위/추정치를 갱신한다. 앞으로 작업 시작마다 추정 기준·완료/남은 일을 안내한다.

기존 Chrome 로드 경로에 extension을 덮어쓰고 새로고침하여 0.1.16을 확인한다. 자료/계정 초기화는 필요하지 않다. develop 병합·자동 병합 없음, 시작 지연 검증 보류 유지.
