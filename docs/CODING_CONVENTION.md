# Coding Convention

## 목적

프로젝트 전체에서 일관된 코드 스타일을 유지하기 위해 작성합니다.

---

## 현재 상태

현재 프로젝트는 아이디어 선정 단계입니다.

기술 스택(Spring Boot / React 등)이 확정되면
언어별 코딩 컨벤션을 추가합니다.

---

## 예정 항목

### Java (Spring)

- 클래스 : PascalCase
- 메서드 : camelCase
- 변수 : camelCase
- 상수 : UPPER_SNAKE_CASE

### React

- Component : PascalCase
- Hook : useXXX
- 파일명 : PascalCase

### 공통

- 들여쓰기
- import 순서
- 주석 규칙
- Commit Convention
