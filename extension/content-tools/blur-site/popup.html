전체 웹 블러 시험 0.3.5

Core 미연결·실험용입니다. 일반 HTTP·HTTPS 웹페이지의 현재 보이는 80px 이상 이미지를 우선 분석하고, 비활성 탭은 새 분석을 대기합니다. 두 모델 모두 민감 점수 75% 이상이면 가리는 시험 기준이며, 오탐을 줄이는 대신 일부 민감 이미지를 놓칠 수 있습니다. 영상 프레임은 대상이 아닙니다. 분석 실패는 가림을 유지합니다. 읽을 수 있는 이미지 픽셀은 그대로 분석하고, 필요한 경우 이미지 원본 주소에서 추가 다운로드하며 외부 분석 서버로 업로드하지 않습니다. Chrome 설정·새 탭·웹스토어 및 iframe 안쪽은 미지원입니다. 탭마다 직접 적용하며 이동·새로고침 후 해제 → 다시 적용하세요.
