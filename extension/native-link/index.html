Windows 프로그램 연결

이 브라우저와 연결하기

이 설치의 Windows 프로그램과 연결만 확인합니다. 계정·비밀번호·집중 기록을 읽거나 서비스를 시작하지 않습니다.

버튼을 누르면 연결을 확인합니다.

서비스 검증은 별도 실행 승인이 필요합니다. 완료 안내까지 이 창을 열어 두세요.

서비스 검증은 아직 시작하지 않았습니다.

보존된 중단 상태

별도 승인이 있을 때만 현재 의무와 회원 신원을 확인합니다. 성공해도 서비스나 집중을 시작하지 않습니다.

현재 설치에 승인된 복구 범위가 있어야 진행할 수 있습니다.

FOCURVE 사용

이 탭은 서비스 연결 유지용입니다. 사용 중에는 주소를 바꾸거나 새로고침·닫기 하지 마세요. 연결이 끊겨도 서비스가 자동으로 정상 종료되는 것은 아닙니다.

  1. 이 탭에서 ‘서비스 시작’을 한 번 누르고 준비 완료를 기다립니다.
  2. ‘집중 팝업을 새 탭으로 열기’를 누릅니다. 주소를 이 탭에 붙여넣지 마세요.
  3. 새 탭에서 집중을 사용합니다. 집중 종료 후 이 제어 탭으로 돌아와 ‘서비스 정상 종료’를 누르고 완료 안내를 기다립니다.
웹 대시보드 열기 집중 팝업을 새 탭으로 열기

정상 사용 모드 승인이 있어야 서비스를 시작합니다.

보존된 집중 종료·복원

승인된 기존 세션의 종료만 확인합니다. 새 집중이나 서비스 재개 권한은 부여하지 않습니다.

현재 신원과 종료 권한 확인이 필요합니다.
