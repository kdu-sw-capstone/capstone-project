# FOCURVE · 목적 기반 집중 환경 관리

학습·업무 목적에 맞게 사이트 이용 환경을 설정하고, 집중 중 자동으로 수집한 접근 기록을 바탕으로 다음 집중 환경을 조정하는 서비스입니다.

**기획·화면·흐름·시스템 설계 자료를 정리하고 본개발을 준비하는 단계입니다.** 세부 정책과 구현 계약의 확정 항목은 [설계 결정사항](docs/design/02_시스템_테크설계/FOCURVE_설계_결정사항.md)에서 관리합니다.

## 서비스 이용 흐름

1. 관리할 사이트를 등록하고 집중·방해·일반으로 분류합니다.
2. 집중 중 차단할 사이트와 이용을 허용하되 기록할 사이트를 설정합니다.
3. 집중 시간을 정하고 세션을 시작합니다. 확장 프로그램이 설정한 정책을 적용합니다.
4. 사이트 접근과 같은 사이트에 다시 접근하려는 행동이 자동으로 기록됩니다.
5. 세션 종료 후 기본 통계와 기록을 확인하고 다음 세션의 설정을 조정합니다.

**목적별 설정 → 집중 세션 → 접근·반복 접근 자동 기록 → 통계 확인 및 다음 설정 조정**

## 개발 범위

| 구분 | 내용 |
|---|---|
| 기본 기능 | 회원·비회원 이용, 사이트 등록·분류, 차단·기록 설정, 집중 세션, Shorts 제한, 접근·반복 접근 기록, 기본 통계, 비회원 자료 가져오기, 화면 모드 |
| 추가 기능 | 추천·댓글·자동재생·Reels 제한, 집중 예약, 일시정지·메모, 이용 시간·행동 분석, 키워드·성인 사이트 제한, 이미지 블러, 행동 기반 AI 피드백 |
| 이번 학기 목표 | Web·Chrome Extension·Server의 기본·추가 기능 구현과 검수·테스트 완료 |
| 후속 확장 | 웹 완료 기준을 충족한 뒤 인력·일정에 여유가 있을 때 PC 확장 착수 |

AI는 설정 조정 후보를 제안하며, 설정 변경은 사용자가 확인한 뒤 적용합니다. Chrome Extension은 이번 학기 웹 서비스의 실행 구성요소입니다.

## 시스템 구성

| 구성 | 계획 기술 | 역할 |
|---|---|---|
| Web | React | 사이트·정책 설정, 세션 관리, 기록·통계 조회 |
| Chrome Extension | Manifest V3 | 브라우저 내 차단·내부 기능 제한, 접근 이벤트 수집, 비회원 로컬 이용 |
| Server | Spring Boot | 인증, 설정·세션·이벤트 처리, 통계 API |
| Database | MySQL | 계정·설정·세션·기록 저장 |

배포 환경과 세부 버전은 구현 환경 확정 시 명시합니다. 현재 설계 자료의 등록은 기능 구현·실행 테스트 완료를 의미하지 않습니다.
